## 一、一页结论：值得验证的不是“视频变书”，而是有边界的任务型知识产品

**当前首选垂直方向仍是周期性 CSV / Excel 导出表处理，但首个 MVP 已收窄：面向需要维护周报 / 月报的中文初级数据运营、业务运营人员，验证“新增本周期文件后，刷新并证明结果已更新且正确；异常则阻断、定位并可回退”的验收型任务包。基础多文件合并与基础刷新不再作为收费核心。¥99只保留为 Gate 通过后的单一付款实验参数。**

这是优先实验，不是已经证实最好的生意。英文市场已找到相关书课购买自述；中文有工具图文产品报价和经营案例，但本轮没有取得该细分的中文直接买方。中文被选为首轮沟通市场，而不是由海外美元价格证明它成立。假定经营者没有现成受众、无已授权专家、无已验证案例；其Excel专业能力、英语分发能力和可用工时未知。

```text
一个重复且可验收的工作任务
→ 官方资料、授权访谈和自己的实际试错
→ 完整解决一个小问题的免费文章 + 免费知识地图
→ 取得正在做该任务的相关读者
→ 发现尚未解决的“下一次、异常情况、交接”问题
→ 一项边界清楚的任务电子书 + 原创练习/工作簿
→ 付款、实际使用、错误率/工时、退款与支持成本
→ 再决定增加教学、工具推荐或其他收入
```

关键判断：

| 问题 | 本轮结论 | 证据/边界 |
|---|---|---|
| 免费内容完整，会不会妨碍收费？ | 不必。便利、练习、迁移到自己任务及反馈都可以收费 | ATBS全书免费仍有正版书销售；购买自述重视练习和讲解，E02/E03/E19/E20 |
| 只整理得更全面是否足够？ | 通常不是足够的差异。免费书课本身也完整 | E07/E17/E19/E23/E31 |
| 第三方热门视频是否不可替代？ | 不是。对步骤和当前接口，官方资料加独立测试往往更直接；访谈价值在经验、判断与例外 | T01/T02；原候选视频来源不完整 |
| 书能不能是核心商品？ | 可以，不能预设必须送书再卖课 | E08/E20/E35；但公开报价不是我们的成交 |
| 有没有从零受众快速复制的证据？ | 没有。中文经营者的起量依赖已有积累、种子群与合作推广 | E38/E41/E50 |
| 现在应不应该建内容平台？ | 不应。先验证特定任务、获取相关读者和实际付款 | 本轮研究判断，不是外部市场事实 |

**两个条件备选：**第一，面向接手遗留代码的开发者，做“一个真实重构案例＋测试与取舍”的电子书；第二，面向已经搭过n8n的人，做故障恢复、重复执行和交接的小班实操。前者有书课购买相邻证据；后者的付费证据更弱，只有当读者明确需要反馈而不是更多教程才验证。

## 二、证据强度：88条仍不等于88个客户

台账现共88条：上一阶段70条，加本轮 Excel / CSV 细任务反向核验18条（E51—E62、T13—T18）。新增记录补充中文岗位、免费/收费替代、公开故障、渠道规则和 Microsoft 官方行为，但没有增加可核验的中文直接买方。旧版51个去重主体、45个来源域名统计只对应原70条，当前不继续用它们冒充更新后的总体统计。

一手买方/付费参与者记录只有4条：E02和E03为Power Query课/书购买自述，E10为重构课程购买自述，E13为付费直播课参与及当时价格自述。明确购买3条、付费课参与1条；无可复核付款凭证。未取得中文直接买方、广告主实际合同、招聘客户成交、授权分销合同及佣金结算证据。

因此可支持的推断是：**特定技术学习者确实会在免费内容以外购买讲解、练习和反馈。** 不能支持的断言是：我们只需整理视频便能获得流量、已有中文人群愿付¥99、广告或招聘已经可盈利。

本研究是目的性样本，容易偏向公开经营的成功者、英语社区和可索引网站。没有付款记录公开不代表没有交易；同样，卖方说有大量学员也不能自动升级成可靠成交。中文精确检索多次没有返回合格本地买方，不能用机器翻译Reddit填补。

### 最有决策价值的几组证据

**已有免费内容后仍买书/课。** E02重视跟做练习，E03提到书中章节与下载文件；这支持任务型练习，不仅是更多概念。E13强调课前环境准备、实做和答疑，说明愿付高价的增量可能是学习过程与反馈，而非课件数量。不同支付主体和产品不能互相换算客单价。

**强免费替代。** Ben Collins免费短课也给完整结构和模板；ATBS免费全书；n8n官方免费课程；DaVinci官方教材、视频和练习。新书需要比“把东西放在一起”更明确的使用优势。E17/E19/E23/E31。

**中文可以卖文字，但冷启动没有被证明。** 少数派的工具专题是可读可购买的图文产品，不证明我们的选题有买家。飞巴的2023复盘自述7天800余订阅、6K+变现，也写到此前失败专栏、既有内容和伙伴推广；不能抹去这些前提再包装成从零复制，更不能当作净利润。E34/E35/E41。

**广告与招聘是另一套买方市场。** Dense Discovery提供赞助报价，Python Jobs HQ提供职位价目；它们证明商业入口存在，不证明我们能卖出去。读者购买、广告主续投和招聘者购买必须独立验证。E43—E46。

## 三、这属于什么生意：市场与付款方地图

它首先是一个**以原创解释和实践支撑的垂直知识品牌**，不是按素材形式划分的“视频整理行业”。书、课、模板、工具及服务是不同的交付；媒体流量、软件推荐和招聘是不同交易，不能把其市场规模相加。

| 层次 | 做什么 | 使用者与付款者 |
|---|---|---|
| 知识来源 | 取得并核验官方资料、原创实验、获授权经验 | 来源作者不是自动付费客户；公开可看不等于可重新出版 |
| 免费内容 | 完整解决一个子问题，公开地图和适用范围 | 相关读者使用；本层可以暂不收费 |
| 知识产品 | 书、练习、代码、工作簿、课堂、判断与反馈 | 个人、团队负责人或雇主为学习/任务结果付款 |
| 商业推荐 | 基于真实适用性的工具或合作产品推荐 | 软件商/作者付佣；读者可能另向商家付款 |
| 广告与赞助 | 把相关受众注意力提供给合适品牌 | 广告主付款，读者不等于广告客户 |
| 职位和项目机会 | 经核实的机会展示或合规转介 | 企业/委托方付款，人才或交付者使用 |

“承接读者的外包项目”是收入；“把内容制作外包给编辑”是成本与组织方式，不能混在一个收入表。

## 四、A/B/C三种经营模式，不默认谁最好

| 项目 | A 客户内容资产化 | B 自营垂直知识 | C 与专家合作经营 |
|---|---|---|---|
| 付款对象 | 已有视频/播客/课程的企业或作者 | 相关读者，成熟后可有广告主等 | 读者/团队；我们与专家分成或付许可费 |
| 客户为什么现在买 | 缺编辑产能、出版或内容复用交付 | 工作、学习或购买触发未被现有替代充分解决 | 同B，加可信专家、原创经验和反馈 |
| 主要获客 | 定向B2B业务开发和既有客户 | 自己获得、持续触达相关读者 | 专家既有受众加共同分发，但不能假定专家一定有受众 |
| 资产与控制 | 项目现金流，部分成果归客户 | 内容品牌、用户关系和产品归属更可控 | 取决于授权、品牌、渠道和退出合同 |
| 交付责任 | 范围、素材权利、编辑轮次、验收 | 正确性、可用性、售后、退款、维护 | 必须写清谁审稿、教学、售后、授权及更新 |
| 扩展风险 | 工时随客户增长，修改失控 | 冷启动与信任最难；内容多不等于流量 | 分成和协调成本、关键人依赖、资料权属 |
| 本轮依据 | PodReacher首篇试用US$75，只是服务供给 | 多个书课/文字/模板样本及4条一手买方记录 | 少数派共创和专业作者产品入口，具体分成未公开 |

结论：**为验证用户希望长期经营的资产，优先B的小产品实验；不是认定B最容易产生现金。** 若现金急迫、已有明确内容客户且素材归属清楚，A更合适，但这次没有这些用户资源。若自己无法独立验证领域知识，而能取得愿意参与审核的专业人士，则C先于独自卖课。没有专家或实测能力时，不应拿AI整理补充虚构权威。

合作合同最低要写：原稿/改编/翻译/代码/图表权利，语言、地区、期限、是否独家，署名，审核和售后，营销权，收入与退款/平台费的分成基数，结算与账目访问，更新和下架/退出。**本轮没有找到可普遍套用的真实分成比例，也没有授权任何谈判。**

## 五、十个候选垂直场景与选择理由

### 评分方法

这是研究者的主观筛选模型，不是市场统计、成交概率、真实专家会审或95分认证。无受众小团队为默认资源；经营者实际能力未知，“能力匹配”统一给2/5，不偷偷使用旧聊天中的项目优势。

12项权重合计100：①具体购买触发10；②问题频率/价值10；③现有产品和支付证据15；④相关受众可达性10；⑤可形成第一方经验10；⑥来源可合法取得5；⑦免费替代下的差异空间10；⑧首品可制作性5；⑨交付/审核/更新成本10；⑩信任/专业责任5；⑪收入方式匹配5；⑫经营者能力资源匹配5。各项1—5，高分有利；总分=各项分数×权重之和÷5。

**权利及关键资质是额外门槛，不可被总分抵消。** 来源得5分表示可主要使用官方事实和原创实践，不表示拿到了任何第三方视频再出版权。没有目标环境验证不得宣称可交付。少于5分的差距不作稳健排序。

|---|---|---:|---|---|

为何不是机械取分数前三：通用Python有较强付费品类证据，但本轮没有证明新书比已有免费完整书更值得买，不能仅靠市场存在去复制。第二备选n8n不是声称胜过66分候选，而是保留“反馈与排错”这一不同的付费缺口；必须额外通过买方验证。不能因为AI热门而加分。

敏感性：首选的支付证据若从4降为2（严格只看中文具体任务），总分降到71；若其可达性再从3降至1，降到67，就不再领先重构。因此当前首选具有明显证据条件，不能据77分直接扩大投入。若用户本人的专业和渠道资源不同，排序应重算。

## 六、首选的免费内容、剩余缺口与首项产品

### 读者必须足够具体

上一阶段把人群写成“运营、行政、初级分析人员”仍然偏宽。本轮用当前中文岗位反向核验后，**首个 Persona 收窄为初级数据运营 / 业务运营人员**：日常需要录入、核对、汇总、清洗和维护数据台账，并协助周报 / 月报。行政和初级分析暂作相邻人群，不再与首个 Persona 混在一起。购买触发候选也从“想学 Power Query”改成**本周期报表截止日前，需要把新导出文件纳入既有报表且必须交出可复核结果**。谁实际付款仍未验证。

首版只处理**数据整理，不做会计政策、报税、审计或经营决策保证**。限制Windows版Microsoft 365 Excel、一个定义清楚的CSV交易流水结构、手动刷新；不承诺Mac一致、ERP连接、无人值守、远程刷新或任何导出格式通吃。E49说明“流程成功”与“数据已刷新”还应分开验证。

| 免费入口（完整交付） | 仍可能剩下的付费缺口 | 对应首品价值 |
|---|---|---|
| 三个导出表怎样合并并核对行数/金额 | 下一月放文件、字段变化、定位错误和回退 | 固定范围的月度作业说明与经验证工作簿 |
| 为什么不能按订单号随便去重；一个完整退款例子 | 更多错误类型、判断顺序和练习反馈 | 故障练习、答案与验收清单 |
| 报表交给同事前的完整自查表 | 可复现操作、版本说明与维护责任 | 交接章节、版本记录和边界 |

**知识地图免费，免费文章不故意缺步骤。** 收费不是把必要步骤藏起来，而是把适用范围内的一次示例扩展成可复用、可查错、可交接的完整任务说明。

首品工作名：**《每月导出表到可复核报表：合并、查错与交接》任务电子书**。仅一个SKU，**建议实验价¥99**；不是已成交价、市场平均价或“应该定价”。第一轮不做¥9.9引流再强推昂贵课，也不同时卖六种东西。

## 十、成本模型：收入、贡献和利润分开

以下数字全部是**本轮实验参数与算术情境，不是经营结果或市场转化率**。人民币与美元/欧元分别算，不做隐含换汇。没有购买、投放或新增付费工具。

### 1. 首品人民币模型

设售价P=¥99；退款率r=5%；平台订单费f=15%；个人结算服务费w=6%（约值，E39）；平均每单支持10分钟；经营者机会成本¥100/小时。假定退款相应订单费可按比例退回；本轮未核验实际合同，若手续费不退需加回成本。实际所得税/适用销售税和个别交易费用未确定，不能称税后净利。

```text
退款后销售额/单 = 99 × 95% = 94.05
支付/平台/结算后现金、未扣支持与税 = 99 × 95% × 85% × 94% = 75.15
每单支持人工 = 10/60 × 100 = 16.67
每单贡献（计人工、税前） = 58.48

首月固定：制作/验证40小时×100 + 独立审稿600 + 模型/托管等200 = 4,800
稳定月固定：内容8小时 + 分发6小时 + 更新4小时，合计18小时×100 + 现金300 = 2,100
稳定月经济利润、税前 = 成交单数 × 58.479333… − 2,100
```

固定工时不含已经按单计入的支持工时，避免重复计人工。月度模型不再次列首月建品费用，但首月损失仍需由以后利润回收。纸书库存、未约定专家分成及未来开发成本不在首版模型内；引入就必须重算。

5个全价订单毛销售¥495；按上述首月模型约亏¥4,507.60。**5单可以提供支付学习，不代表回本。** 稳定月约36单才覆盖其固定成本，仍是税前及上述假设下的结果。

设合格读者到产品页30%，产品页到购买5%，总购买率1.5%。这两个比例是实验输入，未被任何本轮渠道验证。

简短复算代码（仅演算假设）：

```python
from math import ceil
P, r, f, w, hourly = 99, .05, .15, .06, 100
unit = P*(1-r)*(1-f)*(1-w) - hourly*10/60
fixed = 2100
for target in (1000, 10000, 30000):
    orders = ceil((target+fixed)/unit)
    print(target, orders, ceil(orders/.30/.05))
# 输出：1000 54 3600；10000 207 13800；30000 549 36600
```

| 开放许可 | 阅读具体许可，遵守署名、非商业、相同方式共享等 | “开源/免费”四个字不等于无条件商用 |

R01/R02分别对应中国和美国权利边界，不把美国fair use通用化，也不编造改写比例安全线。ATBS的BY-NC-SA许可尤其说明免费全书不是可直接翻译收费的素材库（R03）。重新画图仍可能保留原作表达，不应默认改颜色或改布局就无权利问题。

商业推荐需清楚披露收益关系；无真实使用就不编体验，没有联盟资格就只放普通正版链接（R05/E21/E40）。允许联盟推荐不等于允许转载商品全文或任意广告渠道；n8n当前联盟明确限制付费广告推广。

中国网络出版的实际运营主体、内容形态和许可边界，不能凭某平台有收款按钮就推定已解决（R08）。销售前要按经营地、服务对象、平台/出版社和付款主体核验；本轮不知道用户的注册主体和适用法域，不作经营放行或税务判断。

招聘展示、简历库、人才撮合不是同一责任：当前只做市场研究，不采集简历、不承诺企业撮合，不声称已经具备可能需要的资质。正式模式的资质与个人信息义务当次完整核验不足，维持停止门槛。医疗、金融决策和法律类高责任内容不因客单价高而优先。

## 十七、Excel / CSV 细任务反向核验：首个 MVP 从“教合并”改为“刷新后验收”

### 17.1 先看最强反证：基础合并与基础刷新已经很难单独收费

Microsoft 当前中文官方资料直接用“每月把多个同结构预算工作簿合并并刷新”作为 Power Query 文件夹导入示例，并要求先核对文件列表；官方 CSV 示例本身就是12个月文件。中文 B 站既有免费的 2026 Power Query 系列，也有从 ¥39.9 到 ¥199.99 的系统付费课程，其中已经覆盖文件夹多表合并、追加、清洗、表头 / 数据源变化等内容（T13、E53—E58）。

这说明**“不会合并文件”不是一个足够稳健的 ¥99 差异点**。付费课程存在只证明供给和平台交易形态存在，不能证明本项目的 Persona 会买本产品；页面播放 / 展示数字也不升级为购买人数。

AI 也继续压低基础操作门槛：Microsoft 已允许 Copilot 在一定版本 / 许可条件下从另一个 Excel 工作簿导入数据并建立可刷新的连接；WPS 当前公开营销资料则宣称可用自然语言做 Excel / CSV 跨表合并和异常检测（T18、E61）。后者是供应商宣传，未做本轮独立实测；但足以提醒：首品不能把“会点按钮 / 会写基础 M”当长期付费壁垒。

### 17.3 当前首个 MVP 任务合同

**Persona：** 初级数据运营 / 业务运营人员；已有 Excel 基础，但不是 Power Query 专家。公开招聘样本显示这类岗位需要日常录入、核对、汇总、清洗、排查重复 / 遗漏 / 错误，并协助周报 / 月报（E51）。更高级运营岗位还直接要求 Power Query，同时把 SQL / Python 自动化列为替代或加分工具（E52）。

**业务触发：** 周报 / 月报截止日前，新一批结构约定的 CSV / Excel 导出文件已经到达，需要刷新既有报表并提交结果。

**单一承诺：**

```text
加入本周期输入
→ 刷新
→ 证明正确来源被纳入
→ 证明结果表已真正更新
→ 核对来源数量 / 行数 / 控制量 / 错误
→ 异常则 BLOCK，不静默交付
→ 修正或回退到上一已验收版本
```

首版继续限制 Windows Microsoft 365 Excel + 一个原创合成交易流水结构 + 手动刷新。**不承诺**ERP / CRM API、无人值守 Power Automate、跨所有 Excel / WPS 版本兼容、会计判断、自动决定退款冲突、真实客户表代做。

### 17.4 免费内容解决到哪里，收费假设还剩什么

免费入口应该完整教会“一次正常合并和一次正确刷新”，并直接链接 Microsoft 官方资料；不能故意省略步骤制造付费墙。官方和中文教程已经足以解决：

- 同结构文件夹合并；
- 基础追加 / 清洗 / 更改类型；
- 手动刷新；
- 常见“找不到数据源 / 找不到列”错误的定位；
- 大量基础 Power Query / M 操作。

当前**仍值得做付款实验、但尚未证明有人会付钱**的部分是把这些知识变成一个范围固定的“验收系统”：

1. 输入清单：期望文件、实际文件、文件来源可追踪；
2. 刷新层级：区分编辑器预览、本地缓存、工作表 / 数据模型；
3. 结果控制：行数、唯一记录数、关键合成控制总额、错误单元格 / 被拒绝行；
4. 结构变化：字段新增 / 缺失 / 改名 / 类型异常必须显式失败或进入隔离区；
5. 故障定位：告诉使用者坏在哪个文件 / 行 / 步骤，而不是只报“刷新失败”；
6. 回退：保留上一已验收输出与版本；
7. 最小交接：下一位使用者知道来源位置、刷新方式、验收项和权限依赖。

如果真实用户只需要官方教程 + AI 问答就能稳定完成以上七项，则应停止首品，而不是把材料写得更长。

指南应以完成任务所需长度为准，不再预设40—60页。¥99继续作为**Gate通过后的价格实验变量**，不是当前产品价值已经证明为¥99。

### 17.6 质量 Gate：本轮真实状态

当前 Python 受控样例仍提供一部分“业务规则离线参照”，但**流程执行成功 ≠ Excel 结果正确**。因此同一项必须分别标明离线逻辑与目标环境。

| Gate | 现有离线逻辑 | 目标 Excel / MVP 状态 |
|---|---|---|
| 正常输入 | PASS：3笔合成交易，CNY110.00 | **BLOCKED**：未建 / 未跑 Power Query 工作簿 |
| 重复数据 | PASS：默认阻断；显式批准一致重复后可对账 | **BLOCKED** |
| 退款 / 冲突数据 | PASS：同订单退款保留；同流水号冲突阻断 | **BLOCKED**；真实业务语义仍需独立审核 |
| 字段新增 | PASS：当前严格 schema 会阻断额外字段 | **BLOCKED** |
| 字段缺失 / 改名 | PASS：当前严格 schema 会阻断 | **BLOCKED** |
| 列顺序变化 | PASS：按列名读取 | **BLOCKED**；Microsoft 文件夹合并同样不要求列顺序一致 |
| 非法值 / 类型 | PASS：非法金额、坏日期、混币种等阻断 | **BLOCKED** |
| 刷新 | OUT_OF_SCOPE 于 Python 样例 | **BLOCKED** |
| 刷新后结果核验 | OUT_OF_SCOPE 于 Python 样例 | **BLOCKED** |
| 失败定位 | PASS：样例返回文件 / 行或冲突来源 | **BLOCKED** |
| 回退 | OUT_OF_SCOPE 于 Python 样例 | **BLOCKED** |
| 交给另一人复现 | OUT_OF_SCOPE 于 Python 样例 | **BLOCKED** |

因此：

```text
MVP_PRECHECK = BLOCKED
SALES_READY = NO
```

没有因为新增公开证据就把任何 Excel 项改写成 PASS。

### 17.7 第一批真正相关用户与渠道：只证明“有入口”，没有证明“拿得到买家”

桌面研究能确认三个不同层次：

1. **任务人群存在。** 2026-09-10的数据运营实习岗位明确包含数据核对、整合清洗、重复 / 遗漏 / 错误排查及周报 / 月报；另有运营岗位要求 Power Query 并承受月末 / 季末周期（E51、E52）。
2. **中文学习与交易场所存在。** B站既有免费 Power Query 内容，也有平台内付费课程；这说明可以看到这类学习者、也存在付费内容基础设施，但不证明这些页面数字就是买家，更不证明我们的目标 Persona 可被低成本触达（E53—E58、E62）。
3. **可合规发布完整解法的候选渠道存在，但要过规则。** 少数派 2026-09-16 的审阅规则允许满足条件、明确披露利益关系的宣传内容，Matrix 仍需作者 / 审阅流程；它证明“公开写一篇真实解法并透明说明自己产品”在规则上存在路径，不证明该平台有足够本 Persona（E60）。

Microsoft Q&A 是真实问题和环境差异证据源，不是首轮商业推广渠道（E59）。微信群 / QQ群没有取得公开可核验的准入和推广规则，本轮不计为渠道。小红书 / 公众号虽能找到大量相关内容，但本轮没有完成足以支撑“可外链 / 可售卖 / 可持续触达”的当前规则核验，不将其写成已通过渠道。

所以渠道 Gate 仍未通过。下一阶段若另获外部行动授权，只选择**一个完整内容渠道 + 一个获允许的问题讨论渠道**做小样本，不同时铺六个平台。

### 17.8 继续、调整或停止

本轮不是情况 A 的“按原产品继续”，也没有到情况 C 的“停止整个 Excel / CSV 方向”。当前是：

> **情况 B：保留垂直方向，调整首个产品和任务。**

继续条件：

- 目标 Excel 工作簿在 Windows Microsoft 365 通过本节 Gate；
- 独立审核确认异常阻断 / 控制量 / 回退没有明显错误；
- 后续获授权的真实目标用户中，至少有人明确说官方教程 / AI / 公司 SOP 仍不能让他稳定完成“刷新后验收”；
- 找到一个规则清楚、实际可触达该 Persona 的渠道；
- 然后才允许把 ¥99 当作真实付款实验参数。

停止 / 再调整条件：

- 用户只缺一次设置，AI / 同事 / 官方教程已经足够；
- 每家公司都要重做字段、路径和业务规则，支持迅速变成定制实施；
- 最难部分其实是财务 / 业务判断，而不是可复用的数据验收；
- 无法取得合格目标用户；
- Windows Excel 工作簿对字段 / 路径变化不够可靠；
- 真实使用支持工时逼近服务业务。

**中文直接买方证据目前仍不足，付款凭证仍为0。** 因此本轮不能从“有岗位 + 有课程 + 有故障”跳到“¥99产品已经有市场”。
