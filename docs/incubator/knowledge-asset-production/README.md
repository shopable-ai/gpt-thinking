## 1. 当前要研究什么

> 自己经营一个垂直知识业务：从视频、访谈、课程、文章、官方资料与实践中发现知识，整理成有独立价值的内容，吸引相关读者，再通过书籍、教学、工具、服务、软件推广、广告、会员或招聘等方式变现。

书和电子书可以直接卖，可以是核心产品，不必被限定为赠品或引流材料。也可以研究正规联盟推荐、授权分销和专家合作，并不要求所有商品自己制作。

这里保存方向与问题，并记录研究如何改变建议，不预先宣布市场已经成立或已经盈利。

## 2. 为什么更新方向

之前的讨论与旧提示词主要围绕：客户给出自己的视频，由我们制作文章、Guide / Playbook，再收取服务费。

用户随后明确：主要还要研究自己做内容、卖书、卖课及其他变现，而不是默认只承接内容外包。

因此当前区分三种模式：

| 模式 | 谁经营内容或产品 | 研究位置 |
|---|---|---|
| A. 客户内容资产化服务 | 为客户制作、编辑或维护知识资产 | 保留比较，不默认首选 |
| B. 自营垂直知识业务 | 自己经营受众、内容与相关产品或交易 | 当前优先研究的主线，不等于已验证最佳 |
| C. 与专家合作经营 | 与作者取得授权后联合制作、销售或分成 | 与 A、B 一并比较 |

“服务可能较容易开始”不能替代用户的长期目标；“自营是研究主线”也不能变成一定推荐自营的结论。

旧版服务研究提示词保留在 [更新前的 Git 版本](https://github.com/shopable-ai/gpt-thinking/blob/045114049ddbb198bcc1740bf8ae337e3c0a8d68/docs/incubator/knowledge-asset-production/market-research-prompt.md)。当前同一路径已改用新版，不再同时维护两个互相竞争的主提示词。

## 3. 整体商业主链

```text
具体人群与实际问题
        ↓
视频 / Podcast / 访谈 / 课程 / 文章 / 官方资料 / 实践
        ↓
权利与来源检查，恢复真实知识及必要视觉信息
        ↓
围绕读者任务组织：概念、论点、证据、案例、方法、限制
        ↓
知识地图与完整解决一个子问题的免费内容
        ↓
自己的分发渠道、相关读者与持续触达
        ↓
识别看完之后仍值得付费解决的问题
        ↓
匹配的书 / 教学 / 工具 / 服务 / 推荐 / 商业机会
        ↓
真实付款、交付、使用、退款与复购
        ↓
更新知识、产品与渠道，检验能否持续盈利
```

视频只是知识来源和选题线索，不是产品边界。不能用“三个视频 = 三章”代替知识架构，也不能用补写更多文字冒充新增价值。

## 4. 原始假设与必须检验的问题

原始设想：一条或几条视频可能只覆盖主题的一部分；可以先整理其中已有知识，再向需要的人提供更系统的垂直知识产品。

需要分别验证：

- 读者真正缺系统理解，还是时间、实践、反馈、工具或代为执行？
- 现有免费材料、已有书课、AI 搜索与 Notebook 是否已经足够？
- 更完整的结构能否减少理解或执行困难，而不仅是页数更多？
- 能否取得自己的相关受众，而不是只找到有播放量的来源？
- 谁愿意按什么范围付款，交付、审稿、更新和获客成本是否可持续？

不能预设所有视频都知识密度低；公开报价、关注、收藏和有趣的反馈，不等于成交与利润。

## 5. 免费内容与付费产品的连接

建议研究这条关系，而不是故意删掉关键步骤制造付费墙：

```text
免费内容完整兑现一个小承诺
        ↓
读者的下一项真实任务或剩余缺口
        ↓
范围清楚、能独立使用的付费产品
```

| 读者或企业的下一步需求 | 候选交易 | 需要验证的不是 |
|---|---|---|
| 系统理解、查阅、按顺序学习 | 书、电子书、专题指南 | 仅仅文档更长 |
| 学会操作、得到反馈 | 课程、工作坊、付费教学 | 仅仅把书录成视频 |
| 直接使用、节约搭建时间 | 模板、代码、工作流、资料包 | 仅仅下载次数 |
| 希望别人负责完成任务 | 咨询、外包、实施与维护 | 仅仅有人询价 |
| 选择合适工具或现有学习产品 | 软件联盟、书课推荐、授权分销 | 仅仅推荐点击 |
| 持续获得有效更新或专业判断 | 会员、知识库、情报订阅 | 仅仅每月生成很多内容 |
| 品牌希望接触相关受众 | 广告、赞助、合格线索 | 仅仅总阅读量 |
| 企业希望接触匹配人才 | 职位展示、招聘赞助或合规撮合 | 仅仅有招聘栏目 |

读者、使用者、付费者可以不是同一个人。广告主、软件商、招聘企业有独立采购条件，不能把它们的假设收入直接相加。

## 6. 保留的方向性判断（不是市场事实）

免费内容可以高质量、完整且独立有用；收费产品可提供更好的组织、练习、工具、反馈、便利或持续更新，并非只能卖秘密知识。

先明确人群与任务，再决定适合书、教学、模板、服务还是推荐已有产品。不默认 SaaS、全库知识图谱、一本大书或全部变现方式同时启动。

在研究比较后，优先检验一项主收入，再判断一项自然相关的辅助收入。广告、会员与招聘是否加入，由各自买方证据决定。

“取得来源 → 获得自己的读者 → 成交 → 完成使用”是不同环节，必须分别核查。

## 13. 当前阶段冻结决策与下一次推进门槛

这一节用于防止后续对话重新漂移。它不是新的商业结论，而是把本轮已经形成的判断固定成下一阶段的默认边界；新的直接证据可以推翻它，但不能因为换了对话就重新从“视频转文章工具”开始。

### 13.1 冻结的核心判断

当前研究对象不是“把热门视频批量整理成书”，而是：

```text
一个具体人群反复遇到的、可以验收的任务
→ 用官方资料、合法来源、专家经验与原创实践建立可靠知识
→ 免费内容完整解决一个子问题
→ 找到读者下一项仍未解决的重复使用 / 异常 / 迁移 / 反馈 / 交接问题
→ 用一项范围清楚的知识产品解决
→ 以真实付款、实际使用、退款、支持工时和利润决定是否继续
```

因此，“AI能不能生产更多内容”“能不能把更多视频变成文章/电子书”已经不是当前最重要的验证问题。下一阶段最有价值的新证据，是**中文目标读者是否真实付款、是否真正使用、是否能够独立完成范围内任务，以及交付成本是否可控**。

B（自营垂直知识业务）继续作为首轮实验主体；A（客户内容资产化服务）和C（专家合作经营）保留为条件性转向，不因为自营暂时获客困难就自动把A宣布为更优，也不因为缺专业能力就让AI代替专家审核。

### 13.2 首轮实验暂时固定，不继续横向扩题

在没有新的反证之前，首轮只验证：

- 人群：需要周期性维护周报 / 月报的中文初级数据运营、业务运营人员；行政与初级分析人员暂作相邻人群，不再混成首个 Persona。
- 任务：新增本周期导出文件后，刷新固定报表并**证明结果已更新且正确**；来源文件遗漏 / 重复、字段改名 / 缺失、非法值或路径问题必须显式阻断并可定位，不把“刷新按钮执行成功”当作业务结果正确。
- 首品：验收型任务包（短指南 + 原创合成练习 + 经 Windows Microsoft 365 Excel 实测的 Power Query 工作簿 + 验收 / 回退 / 最小交接清单），不先写40—60页大书。
- 实验价：¥99 暂保留为 Gate 通过后的单一价格实验参数，不是市场价、已成交价或当前销售授权。
- 第一收入：读者购买首品。
- 第二收入：只有真实买方进一步暴露“需要反馈 / 工具 / 代做 / 持续更新”时再单独验证。

遗留代码重构电子书和n8n故障恢复小班仍是两个备选，不与首选并行启动。除非首选因买方、渠道、质量、权利或成本门槛失败，或出现明显更强的新证据，否则不重新扩大到十几个方向再评分。

### 13.3 下一轮不再做什么

默认不继续：

1. 为证明方向合理而继续堆更多视频、工具、开源项目和内容生产能力。
2. 再生成一份相似的市场研究提示词、商业模式总览或“更完整”的知识架构。
3. 在没有新增买方证据时继续微调10个候选的主观分数。
4. 在没有真实广告主、联盟结算或招聘企业证据时，把广告、联盟、招聘收入加入首轮收入预测。
5. 在没有目标环境验证和独立审核前，直接写完整书、宣称产品已可销售或扩大内容产量。
6. 用英文市场报价、平台订阅量、点赞、收藏、公开价格或经营者宣传替代中文目标人群的真实购买与使用证据。

### 13.4 下一阶段只有四类证据可以显著推进判断

按优先级补：

1. **目标用户证据**：真实负责该任务的人最近怎样做、哪里出错、用什么免费替代、是否曾为类似解决方案付钱。
2. **渠道证据**：能否在合规且可持续的渠道触达足够多真正执行该任务的人，而不是得到泛流量。
3. **交付证据**：Windows目标Excel环境中，工作簿和说明能否被别人复现；异常、回退、字段变化与交接是否可靠。
4. **交易与使用证据**：在另获外部行动授权后，记录产品页访问、真实付款、退款、实际使用、完成率、求助工时和后续需求。

若只是新增来源、文章数量、视频摘要、AI生成页数或工具跑分，而没有改变上述四类证据之一，不应据此提高商业判断的置信度。

### 13.5 阶段 Gate

在进入真实商业验证前，至少应满足：

- 目标任务定义没有继续扩张；
- 免费替代已经实际核查，而不是假设其不足；
- 工作簿在目标环境通过适用测试；
- 关键业务语义和错误处理经过独立审核；
- 来源和商业使用边界清楚；
- 有一个可合规触达目标读者的实际渠道。

获得外部行动授权后，才执行访谈、分发、预售或销售。实际付款之后仍不能直接宣布商业模式成立，还要继续看实际使用、退款、支持工时和贡献利润。

如果约100个合格产品页访问仍0单，或实际任务用户普遍认为免费替代已经足够，停止当前SKU/承诺并回到需求判断；如果根本无法取得合格访问，则只判定渠道尚未验证。若权利不清、产品错误可能影响真实业务、支持成本失控或购买后长期不使用，也应暂停或缩小范围，而不是继续增加内容。

### 13.6 文档接续规则

后续默认按以下顺序工作：

```text
README.md（当前状态与冻结决策）
→ research-report.md（完整研究、模型和实验设计）
→ evidence.md（回查证据）
→ controlled-sample.md（查看已实际验证的样例）
```

只有出现新的真实证据、实验结果或被证伪结论时，才增量更新研究报告与证据台账。不要为了保存聊天摘要再创建重复的“商业模式”“结论”“下一步”文件。

## 14. 2026-09-22 Excel / CSV 细任务反向核验后的冻结修订

本节用新增证据修订第13节的“宽任务”默认值；第13节的方法和 Gate 不变。结论不是“Excel 已找到市场”，而是**宽方向尚可继续，小任务与产品形态必须收缩**。

### 14.1 为什么不再把“多文件合并”作为收费核心

Microsoft 当前中文官方资料已经直接覆盖“同结构文件夹合并 → 每月刷新”的典型场景，并要求核对文件列表；B站同时存在完整免费 Power Query 系列，也存在 ¥39.9、¥98、¥99、¥199.99 的付费 Power Query 课程。说明：

- 基础合并、追加、刷新本身已经高度商品化，免费替代很强；
- 有收费供给不等于我们拿到了中文直接买方证据；
- 若首品只是“更完整地讲一遍 Power Query”，¥99 没有足够新的收费理由；
- Copilot / WPS AI 等自然语言数据能力还在进一步降低基础操作门槛，不能把“会写 M / 会点合并”当长期壁垒。

### 14.2 当前首个 MVP 任务

```text
初级数据运营 / 业务运营人员
→ 周报或月报截止日前取得本周期 CSV / Excel 导出文件
→ 放入约定来源位置并刷新固定工作簿
→ 证明应有文件均被纳入、结果表确实更新、关键控制量一致、没有被忽略的错误
→ 若来源 / 字段 / 值 / 路径异常则阻断交付并指出故障位置
→ 能回到上一个已验收版本
```

**首个结果承诺只到“刷新后的数据产品可以被复核”，不包含会计政策、退款责任判断、ERP 接口开发、无人值守远程刷新、所有企业格式兼容或不限次排障。**

第一备选收窄为“字段改名 / 缺失 / 类型变化后的安全恢复与影响核验”。“相同结构文件合并”降为免费入口；“退款 / 冲突业务判断”暂不作为首个独立收费任务；“跨人交接”保留为首品的最小验收项，不单独立项。

### 14.3 当前 Gate

当前整体状态仍是：

```text
MVP_PRECHECK = BLOCKED
```

原因不是基础 Power Query 做不到，而是尚缺：

1. Windows Microsoft 365 Excel 中的真实 Power Query 工作簿与刷新测试；
2. 第二位陌生使用者按说明独立复现；
3. 独立专业审核，确认控制量、异常阻断和回退设计不会误导真实工作；
4. 中文目标岗位“最近一次任务 + 当前替代 + 是否付过钱”的直接证据；
5. 一个已核实规则、能持续触达该 Persona 的实际发布 / 交易路径；
6. 真实付款与使用结果（需另获外部行动授权后才允许执行）。

因此本轮结论属于**情况 B：调整产品，而不是直接进入销售**。方向没有被证伪，但原“教程型电子书”形态已被明显削弱；若后续目标用户普遍认为官方教程、公司 SOP 或 AI 已足够，或者工作簿必须大量个别定制才能用，应停止该 SKU，而不是继续补页数。
