# 知识资产生产服务：市场机会、产品形态与商业验证 Prompt

Status: Incubating Research Prompt
Date: 2026-09-22

## 1. 任务定位

研究一个潜在业务：

> 将专家、Founder、企业、Creator 已经拥有的大量 YouTube、Podcast、Webinar、课程、访谈、演讲等长内容，转化为结构化、可信、可阅读、可搜索、可持续更新并能够产生商业价值的知识资产。

技术可行性已有独立基线：`technical-baseline.md`。

本轮不要把主要精力放在“AI 能不能把视频转文字”，真正需要回答：

~~~text
这个市场是否存在？
↓
谁有强需求？
↓
为什么愿意付钱？
↓
现有替代方案为什么不够？
↓
什么交付物最值钱？
↓
一次性还是持续需求？
↓
怎样找到第一批客户？
↓
能否在 30 天内验证真实付费？
~~~

## 2. 不预设商业判断正确

以下仅是假设：

~~~text
高价值长内容中存在大量未被文字资产化的原创知识
+
专家 / Founder / 企业已有大量长内容
+
这些内容没有形成系统 Knowledge Asset
+
AI 可以显著降低知识提取、重组和编辑成本
+
Knowledge Asset 可以支持 Search / AI Search / Lead Generation / Sales / Training
~~~

必须主动寻找反证。若发现需求弱、SaaS 已足够、人工编辑成本过高、版权限制严重、Search 价值不足、客户无持续预算或获客成本过高，应明确降低机会判断。

## 3. 研究资源优先级

~~~text
P0 真实客户需求与价格                 35%
P1 客户分群 / Job-to-be-Done          20%
P2 竞品 / 替代方案 / 服务供给          15%
P3 可卖产品与商业模式                  15%
P4 受控 Demo 与交付成本                10%
P5 技术基线差异复核                     5%
~~~

如果资源有限，宁可少看几个开源项目，也要多获得真实客户需求、价格和购买原因。

## 4. 市场地图

不要预先把市场叫作 Video-to-Blog 或 AI Summarizer。

调查相邻市场：Content Repurposing、Knowledge Repurposing、Content Atomization、Thought Leadership、Founder Content、Ghostwriting、Podcast-to-Book、Course-to-Book、Knowledge Management、Knowledge Base、Digital Publishing、SEO Content、GEO/AEO、Sales Enablement、Training Content、Expert Knowledge Capture。

输出 `Knowledge Asset Production Market Map`，区分：成熟市场、邻近市场、共享预算、仅技术相似但购买者不同的市场。

## 5. P0：真实需求证据

优先搜索 Upwork、Fiverr、Contra、LinkedIn Jobs、Reddit、Indie Hackers、Product Hunt、G2、Capterra、Agency 网站、Ghostwriting 服务、Podcast/YouTube/SEO/Founder-content agency、Course-to-book / Podcast-to-book 服务、Creator/Founder/Consultant/Coach 社区。

重点寻找：YouTube → Blog、Podcast → Article/Newsletter、Webinar → Content、Podcast/Course → Book、Founder Video → LinkedIn、Video Library → Knowledge Base、Training Library → Documentation、Thought Leadership Repurposing、Sales Enablement。

目标：至少 50 个高相关样本。每个尽量记录来源、日期、客户类型、原始需求、已有内容、希望结果、预算/价格、一次性/持续、交付周期、替代方案、购买触发和最大痛点。

严格区分：真实购买需求、真实服务报价、产品营销声明、用户评论、AI 推断。

## 6. 优先验证“已有内容没有被充分利用”

重点寻找 Founder 有几十/几百个视频、Podcast 上百期、Coach/Consultant 有课程、SaaS 有 Webinar/Demo/Interview Library、企业有 Conference/Training Archive，但没有 Knowledge Map、Guide、Book、FAQ、Glossary、Pillar Content、Knowledge Hub、Training Material、Sales Enablement、Searchable Knowledge Base 的案例。

必须回答：客户是否真的愿意为“把已有内容变成长期可复用资产”付费。

## 7. 客户 Job-to-be-Done

至少研究：B2B SaaS Founder、Consultant、Coach、Course Creator、Podcast Host、YouTube Educator、Developer Education、Enterprise Webinar Team、Marketing Department、Training Company、Conference Organizer、Research Organization，以及 Real Estate、Finance、Legal/Medical 等专业教育。

对每类分别评估：需求强度、支付能力、重复需求、交付可标准化程度、获客难度、风险、长期价值，并用证据选择 Top 1 + 两个备选 ICP。

## 8. 客户真正购买的结果

不要默认卖文章。比较：Transcript Cleanup、Long-form Article、Founder Knowledge Guide、Podcast/Course → Book、Knowledge Map、FAQ/Glossary、SEO Pillar Cluster、AI Search/Citation-ready Knowledge Base、Sales Enablement Library、Training/Onboarding、Knowledge Hub、Ongoing Retainer、Content Repurposing Subscription。

对每种产品回答：购买者、购买原因、预算来源、验收方式、一次性/持续、SaaS 替代风险、人类判断占比、毛利潜力。

## 9. 单独研究 Book / Guide

研究 Podcast-to-Book、Course-to-Book、YouTube-to-Book、Expert/Founder/Thought Leadership Book、AI Ghostwriting、Playbook Creation、Executive Ghostwriting。

拆解传统成本：采访、转录、主题发现、去重、章节架构、保持作者 Voice、论证恢复、事实核验、案例整理、编辑、引用、出版。

判断“知识书”究竟是最终商品，还是 Knowledge Architecture 过程中的一种输出。

## 10. SEO / AI Search 必须证伪式研究

不要默认“视频 → SEO Blog = 商业价值”。核查 2026 年 Google Search、AI Overviews、AI Mode、ChatGPT Search、Gemini、Perplexity、GEO、AEO。

区分低价值批量改写与真正新增价值：原创专家知识、第一方经验、独特案例、事实核验、原始数据、清晰结构、引用、跨来源综合、可验证论点。

最终判断 Search 是核心购买理由还是附加价值。

## 11. Copyright / Rights

客户自己的内容与第三方公开内容必须分开研究。

客户自有内容重点研究授权范围、品牌 Voice、长期资产化。

第三方公开内容要区分个人研究/引用/评论/综合研究，与大规模改写后重新出版、商业销售、SEO 批量生产。公开可访问不等于可自由商业再出版。

## 12. 竞品与替代方案

至少研究 Castmagic、Podsqueeze、Descript、OpusClip、Taja、VideoToBlog、Swell AI、ContentFries、Repurpose.io、Letterdrop、NotebookLM、Gemini、Ghostwriting agencies、Podcast repurposing agencies、Course-to-book、Podcast-to-book、Founder-content、SEO agencies、Knowledge-management tools。

不要只比较 Feature；比较 Input、Target Customer、Core Job、Output、Pricing、Human involvement、Knowledge depth、Multi-source、Multi-video、Citation、Verification、SEO/AI Search、Book、Knowledge Hub、Publishing、Ongoing service。

重点找：为什么用户仍然购买人工服务，而不是只使用 SaaS。

## 13. 商业模式

比较 Done-for-you Service、Productized Service、Agency、Consulting + Production、Software-assisted Service、Subscription、Per-book、Per-project、Per-video、Per-month、Knowledge Hub Retainer、SaaS、Marketplace。

重点验证：是否应该先做 Software-assisted Service，通过真实服务找到 PMF，再产品化。

## 14. 技术部分只做差异复核

默认继承 `technical-baseline.md`：Transcript-first、ASR fallback、Speaker/Visual 按需、Canonical Source Package、Knowledge Extraction Patterns、Transcript ≠ Article、Knowledge Asset ≠ Summary。

不要重新系统研究所有 Whisper、yt-dlp 和 Video Summarizer。只在真实 Demo 或商业交付要求证明基线不足时，局部打开技术决策。

## 15. NotebookLM / Gemini 定位

不要只问它们能不能处理视频，而要判断其角色：Extractor、Source Workspace、Research Engine、Verification Assistant、Knowledge Synthesis Layer、Final Writing Tool、Customer-facing Product。

优先验证：

~~~text
Media Extraction Layer
↓
Canonical Source Package
↓
NotebookLM / Gemini
↓
Research / Synthesis
↓
Knowledge Asset
~~~

是否比 `YouTube URL → NotebookLM → 文章` 更适合可控商业生产。

对每层回答：客户是否愿意付钱、是商品层还是内部生产层、是否已被工具商品化、需要多少 Human Judgment、是否可能形成壁垒。

## 17. 受控案例

使用 `https://www.youtube.com/watch?v=uhJJgc-0iTQ`。

不要只证明可以转录，而要比较：普通 AI Summary 与 Canonical Source → Semantic Units → Claims → Concepts → Arguments → Examples → Frameworks → Knowledge Map → Book Outline → 一个章节 → Pillar Page → FAQ 的质量差异。

记录 evidence/timestamp、视觉遗漏、人工修订时间和粗略交付成本。

## 18. 主动获客实验

寻找一个有 50–200 个公开视频但 Blog/Guide/Knowledge Hub 较弱的专家/Founder，自动生成 Content Asset Audit：已有内容小时数、核心主题、重复高价值问题、可形成的 Pillar Topic/FAQ/Guide/Book，以及当前资产缺口。

再用 1–3 个视频制作 Demo。重点寻找真实类似销售模式和转化证据。

## 19. MVP / 最小可卖服务

最终必须提出一个最小可卖服务 + 两个备选。每个具体到：目标客户、触发场景、输入、交付物、周期、人工参与、预计成本、市场价格证据、试单价格、验收标准、复购路径、Upsell。

价格必须尽量基于真实市场证据。

## 20. 30 天验证计划

~~~text
Week 1
→ 需求与竞争证据
→ 选 Top ICP

Week 2
→ 5–10 个真实客户 Content Audit
→ 制作 2–3 个 Demo

Week 3
→ Outreach
→ 真实销售对话
→ 报价

Week 4
→ 争取 Paid Pilot
→ 复盘交付成本和购买原因
~~~

必须定义 Continue / Pivot / Stop 条件。客户愿意看 Demo、觉得有价值、愿意聊，都不等于验证成功；愿意付费或签 Paid Pilot 才是强证据。

## 21. 最终必须回答

1. 这个机会是什么、市场边界是什么？
2. 谁的问题最痛、谁最有支付能力？
3. 客户真正购买什么结果？
4. 为什么今天购买，而不是继续使用 SaaS？
5. 哪些环节已经商品化，哪些仍需要专业判断？
6. Book 是商品还是中间资产？
7. Search / AI Search 是核心还是附加价值？
8. Top 1 ICP 和两个备选是谁？
9. 最小可卖服务是什么，真实价格如何？
10. 前 10 个潜在客户怎样找，Demo 做什么？
11. 技术基线是否足以交付？
12. 最大风险、继续条件和停止条件是什么？

## 22. 输出结构

按以下顺序：一页式机会结论 → Top ICP → JTBD → 真实需求证据 → 市场地图 → 竞品/替代方案 → 客户真正购买的结果 → 产品/服务形态 → 价格与商业模式 → Value Chain → 技术差异复核 → NotebookLM/Gemini → SEO/AI Search → Rights → MVP → Demo → 前 10 个潜在客户 → 30 天验证 → Continue/Pivot/Stop → 未验证问题。

## 23. 证据要求

优先官方产品文档、GitHub 原仓库、官方 Search 文档、论文、真实 freelance 项目、真实招聘、真实 agency/service/SaaS 定价、客户评价、Reddit/Creator/Founder 讨论。

降低 AI SEO 农场、无来源市场规模文章、营销软文、SaaS listicle。

重要判断明确标记 `[事实]`、`[市场证据]`、`[合理推断]`、`[待验证假设]`，价格、需求、法律、产品能力和 2026 年市场事实必须给来源与日期。

## 24. 最终目标

> 不是回答“怎么把视频转成文章”，而是回答：能否围绕客户已经拥有却没有充分利用的原创内容，建立一个他们愿意持续付费的 Knowledge Asset Production 业务；如果可以，先卖给谁、卖什么、怎么定价、怎么证明价值、怎么在 30 天内取得真实付费证据。
