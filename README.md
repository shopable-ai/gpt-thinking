# gpt-thinking｜想法与研究暂存仓库

这里保存讨论中值得继续推进的灵感、问题、候选方案、商业模式与研究提示词。

当前目标是先保存、能找到、能接着研究，再根据验证结果整理；不是现在就建立庞大的知识分类系统。

## 从这里开始

- [孵化区索引](docs/incubator/README.md)：所有探索中主题的入口与轻量存放规则。
- [垂直知识内容与多元变现](docs/incubator/knowledge-asset-production/README.md)：当前核心思路、研究范围、历史变化和下一轮入口。

## 基本约定

暂存不等于随时丢弃。每个值得继续研究的主题，保留一份可读总览；详细提示词与必要资料放在同一主题目录。

新主题优先进入 `docs/incubator/<topic>/`。不预先创建空分类目录，不把未经验证的想法当作既定商业决策。

市场结论、产品能力与价格按来源和日期核验；阶段性结论可以推翻，但保留改变的原因与历史。成熟后再决定归档位置或迁往执行项目。
